## Korpora 0.5.2

- **Your windows come back.** After you quit Korpora or it restarts (an update, say), the concordances you had open return as they were: the query, the sort and other operations, the selected row and the scroll position, and the frequency, collocation and dispersion windows you had opened from them, in their places. Searches run again when a window is shown, so a session with many concordances starts fast. Closing a window still discards its concordance, and nothing asks to save. A concordance you have not saved shows "Edited" in its title: that is the system's draft, not a warning.
- **Quit works with a sheet open.** ⌘Q, the Dock's Quit and an update's relaunch used to do nothing while the New Concordance sheet (or any sheet) was open, without a word; they now close it and go on.
- If your windows still don't come back, check System Settings > Desktop & Dock: **"Close windows when quitting an application"** must be off. macOS then reopens no app's windows.
