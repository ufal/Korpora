## Korpora 0.5.3

- **Regular expressions read characters, not bytes.** In a query, `.` is now one character in every script, a class like `[無非毋不沒莫]` matches those characters (it used to match single bytes, so words without any of them appeared in the results), and a length such as `.{4}` counts characters. Unicode properties work too: `\p{Han}`, `\p{Cyrillic}`, `\P{Han}` for what is not Han, `\p{Lu}` for capitals, and `(?i)` knows non-Latin letters. This changes results of queries that had non-ASCII text in a regular expression: they were wrong before.
- Lookaround and backreferences in a regular expression are still read as bytes (a limit of the engine); everything else above is not affected.
