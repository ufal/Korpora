## Korpora 0.5.1

- **Universal Dependencies import.** A UD corpus imported in Korpora now has the language of each file, as the one built with pando's script has: `text.langcode`, `text.treebank` and `text.id` from the file names, and from UD's language table `text.lang` (the language name), `text.lang_iso3`, `text.lang_family`, `text.lang_genus` (the branch: Germanic, Slavic, ...) and `text.lang_script`. Search or make a subcorpus by language, family, branch or script. Import UD again to get them: the files you pick are not changed, and the import needs room for temporary copies while it runs.
- **Matches.** Only the words a query really matched are highlighted; a word that stands between them (in a dependency, say) is plain. The match colour is red, so it no longer blends with the selection, and you can change it in Settings > Appearance.
- **Corpora.** Reorder the list in Settings > Corpora by dragging, or by clicking a heading. The first corpus is the one a new concordance starts with.
- **Appearance.** Settings > Appearance can keep Korpora light or dark whatever the Mac is set to (System is the default).
- **Attribute lists** (subcorpus pickers, the frequency menu) are in order: `text`, `doc`, paragraph and sentence first, attributes alphabetical, the many sentence translations of UD last.
