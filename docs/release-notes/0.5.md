## Korpora 0.5

- **Frequency distributions over the nodes of a query.** The query and its first hit are shown with every token as a coloured, named node. Click a node, pick an attribute, and it becomes a line of the table; the node and the attribute of a line can be changed afterwards. Count several nodes and attributes together, set ignore case and the order of each line, drag the lines to reorder them.
- **Collocations around a node.** The same view for collocations: click a node to take the window around that word only, or keep the whole match.
- **Query bar.** Completion after `::` knows the attributes of your named tokens, completes region tags and their attributes, and stays out of strings and regular expressions. Better colouring and auto-pairing.
- **Updates.** Korpora can check for new versions: Korpora > Check for Updates. (Install this version by hand; later ones can update themselves.)
- Settings > Appearance fills the window when it is resized.
